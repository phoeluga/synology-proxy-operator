# Security Policy

## Supported Versions

Only the latest released version of `synology-proxy-operator` is supported with
security fixes. Please make sure you are running the latest tag before
reporting an issue.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately via
[GitHub Security Advisories](https://github.com/phoeluga/synology-proxy-operator/security/advisories/new).
This creates a private discussion with the maintainer and allows a fix to be
prepared and released before the details become public.

You should receive an initial response within a few days. Once a fix is
available, a new release will be published and the advisory will be
disclosed.
